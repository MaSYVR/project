# project
## Overview
project is a repository set up to complete Assignment 6 for the dstoolbox course. 
The tasks required for the assignment were:
* Rename files to make meet the 3 principles 
* Organizing the project to meet requirements for a structure
* Setting up a virtual environment and creating an environment file to allow set up on different OS
## The data science tool
I didn't produce this code, but as far as I can tell it involves using scikit-learn to train a logistic regression model based on a provided dataset, with the following step:
1. Load the dataset from a CSV file to a df
2. Print the df structure
3. Print the statistical description of the df
4. Visualize the dataset on a scatter plot and print to png
5. Split the data into training and test data
6. Train a logistic regression model
7. Evaluate the model on the testing set
8. Visualizing the model predictions on a scatter plot and print to png
